# Proposal

## Why

課堂搶答需要老師手動統計各組答案與先後，難以同步管理作答階段，也不易保留、審核及回填結果。本變更建立一個以房間與組別為單位的即時搶答系統，讓老師能公平仲裁答案並將課堂成果帶回 Guided Notes。

## What Changes

- 建立老師房間與房間代碼；學生以房間代碼及組名加入，每組同時限一個有效視窗。
- 依單題或題組 Guided Notes 範本匯入題號與分組關係；學生依題目作答，題組須完整填寫並一次送出。
- 透過 WebSocket 同步房間成員、活動階段、同組已送出狀態、老師端進度與結果；作答期間學生不得看到其他組答案或進度。
- 由伺服器依接收順序仲裁順位，支援老師駁回、順位遞補及每組獲勝題數上限；題組勝出時一併取得其所有題目，並按題數計入上限。
- 活動結束後向全班公布各題得主與答案；提供搶答歷史 CSV、回填 Guided Notes 的新檔案，以及隱藏控制項的大螢幕投影視圖。
- 伺服端與服務層使用 Python，頁面使用 HTML/CSS，並以 WebSocket 提供即時狀態同步。

## Capabilities

### New Capabilities

- `room-session`: 老師建立房間、學生以唯一組別身分加入，以及房間階段同步。
- `guided-notes`: 匯入單題／題組 Guided Notes 題號與題組結構，並將答案回填至原題空格後輸出新檔案。
- `answer-racing`: 組別作答與送出、隱私、伺服器順位仲裁、老師審核遞補及獲勝上限。
- `race-results`: 活動結束公布結果與匯出完整搶答歷史 CSV。
- `classroom-projection`: 提供大螢幕投影專用視圖，呈現倒數、各題得主與組別排行榜。

### Modified Capabilities

無；目前沒有既有規格。

## Impact

- 新增 Python 伺服端與服務層、HTML/CSS 使用者介面及 WebSocket 即時通訊。
- 新增房間、組別、題目／題組、提交、排名、審核與活動結果等持久化資料及 API／事件契約。
- 需讀取使用者提供的單題與題組 Google 試算表範本，並輸出保留原題空格位置的已填答講義副本。
- 需處理房間代碼、組別唯一加入鎖定、重連同步、提交去重、伺服器時間排序與 CSV／講義檔案下載。
